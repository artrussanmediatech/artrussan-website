# Artrussan Website
Responsive multi-page static website for Peter Albert Sansan / Artrussan — technology, design and Papua New Guinea resources.

## Pages
- `index.html` — Home
- `about.html` — About Peter
- `services.html` — ICT support, web development, creative design, networking, Starlink Business, library/digital archives and ICT project documentation
- `portfolio.html` — Portfolio and project areas
- `png-corner.html` — Papua New Guinea Corner
- `png-government.html` — searchable starter directory of PNG public institutions
- `contact.html` — email, WhatsApp and contact details

## Test locally
Extract the ZIP and open `index.html` in a browser. Test navigation, mobile menu, directory search and the contact form. The contact form prepares an email in the visitor's email application; it does not send or store messages on a server.

## Upload to FreeHosting
1. Open File Manager and enter `htdocs`.
2. Back up the current site files before replacing anything.
3. Upload the **contents** of this ZIP directly into `htdocs`, so `index.html` is immediately inside `htdocs`.
4. Keep the `assets` folder and filenames unchanged.
5. Visit your domain and press `Ctrl+F5` to refresh cached files.

Do not upload the ZIP itself as the website root; extract it first.

## Before publishing
- Verify contact details and public-facing address information.
- Check every external government URL; PNG Corner is an independent resource, not an official government website.
- Portfolio entries describe project areas and should be updated with approved screenshots, public links and outcomes before being presented as completed client work.
- Google Fonts load online; fallback fonts are included.

Plain HTML, CSS and JavaScript. No framework, database or build step required.
